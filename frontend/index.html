Data Sources & Methodology

Champion names, classes, and community tier rankings were collected from MCOC.app .

Data is processed using Python and Pandas, stored in SQLite, and served through a FastAPI backend.

This dashboard currently contains a limited sample of champions. Community tier rankings are subjective and are not official Kabam ratings.

This is an independent educational project and is not affiliated with Marvel, Kabam, or MCOC.app.
